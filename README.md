# Caderno de Python

Guia de estudo de Python para quem está começando em lógica de programação.

- 16 lições, de algoritmos e tipos até vetores, registros e funções
- Exemplos que rodam direto no navegador (Python via [Brython](https://brython.info))
- Referência das funções embutidas e dos métodos de `str`, `list`, `dict` e `set`
- Moldes de "como montar" cada tipo de programa
- Exercícios de lógica com correção automática
