Do algoritmo em português ao Python

Um algoritmo é uma sequência finita de passos claros que resolve um problema. Programar é escrever esses passos numa língua que o computador entende.

Os três blocos de todo programa

Quase todo exercício da lista tem o mesmo esqueleto: entrada → processamento → saída. Antes de escrever código, separe essas três partes.

PartePerguntaExemplo: média de 3 notas
EntradaQuais dados eu preciso receber?nota1, nota2, nota3
ProcessamentoQue conta ou decisão eu faço com eles?media = (nota1 + nota2 + nota3) / 3
SaídaO que eu mostro no final?a média
nota1 = float(input("Nota 1: "))   # entrada
nota2 = float(input("Nota 2: "))

media = (nota1 + nota2 + nota3) / 3  # processamento

print("Média:", round(media, 2))   # saída

A Torre de Hanói (exercício 10) tem uma solução famosa em Python. Rode e veja os movimentos para 3 discos:

def hanoi(n, origem, destino, auxiliar):
    if n == 1:
        print(f"Mova o disco 1 de {origem} para {destino}")
        return
    hanoi(n - 1, origem, auxiliar, destino)
    print(f"Mova o disco {n} de {origem} para {destino}")
    hanoi(n - 1, auxiliar, destino, origem)

Regras para nomes (identificadores)

Exercício 17. Um nome válido:

  • começa com letra ou _ (nunca com número): b248 ✔, 3x4 ✘
  • tem só letras, números e _: nota*do*aluno ✘, km/h ✘, ah! ✘
  • não tem espaço: nome empresa ✘ → use nome_empresa
  • não é palavra reservada (if, for, class…) e diferencia maiúsculas: Maria ≠ maria

Convenção em Python: snake_case, tudo minúsculo com _: salario_liquido, total_vendas.

Conversão entre tipos

input() sempre devolve texto. Para fazer contas, converta:

print(int("42") + 1)       # 43
print(float("7.5") * 2)    # 15.0
print(str(10) + " anos")   # '10 anos'
print(int(9.99))           # 9  (corta, não arredonda)
print(round(9.99))         # 10
print(bool(0), bool(5), bool(""), bool("oi"))  # False True False True
print("5" + "5", 5 + 5)    # 55 10  (texto junta, número soma)

Atribuição múltipla e troca

Os exercícios 41 e 57 pedem para trocar o conteúdo de A e B. No Portugol você usa uma variável auxiliar. Em Python dá para fazer dos dois jeitos:

Lição 4 · Teste de mesa

Teste de mesa: rodar o programa na cabeça

Fazer teste de mesa é executar o algoritmo à mão, linha por linha, anotando o valor de cada variável numa tabela. É o melhor jeito de achar erros de lógica.

Como fazer

  1. Desenhe uma coluna para cada variável.
  2. Leia uma linha do algoritmo por vez.
  3. Toda vez que uma variável recebe valor, escreva o novo valor embaixo (risque o antigo).
  4. Nas decisões (if), calcule a condição e siga só o caminho que deu verdadeiro.

Pratique: exercício 27

O algoritmo lê x e y, calcula z = x*y + 5 e classifica: z <= 0 → A, z <= 100 → B, senão → C. Preencha a tabela e clique em conferir.

XYZResposta

Depois confira com o Python:

for x, y in [(3, 2), (150, 3), (7, -1), (-2, 5), (50, 3)]:
    z = (x * y) + 5
    if z <= 0:
        resposta = "A"
    elif z <= 100:
        resposta = "B"
    else:
        resposta = "C"
    print(x, y, z, resposta)

Lição 5 · Sequência

Entrada, contas e saída

Estrutura sequencial: as instruções rodam uma depois da outra, de cima para baixo, sem desvio. É o capítulo dos exercícios 33 a 71.

print: mostrar na tela

print("Olá, mundo!")
print("Soma:", 2 + 3)            # vários itens separados por espaço
print("a", "b", "c", sep="-")    # muda o separador
print("sem pular linha", end=" ")
print("continua aqui")

input: ler do teclado

O texto entre parênteses é a mensagem que aparece para o usuário. O resultado é sempre str.

nome = input("Seu nome: ")
idade = int(input("Sua idade: "))        # inteiro
altura = float(input("Sua altura (m): "))  # real
print(nome, "tem", idade, "anos e", altura, "m")

Esqueceu de converter? input("x: ") + 1 dá TypeError (texto + número). Sempre use int(...) ou float(...) em volta do input quando o dado for número.

f-strings: formatar a saída

Coloque um f antes das aspas e as variáveis entre { }. Para dinheiro, use :.2f (duas casas).

nome = "Carla"
salario = 2500
novo = salario * 1.22
print(f"{nome} vai receber R$ {novo:.2f}")
print(f"{0.1534:.1%}")        # porcentagem: 15.3%
print(f"[{'dir':>8}]")         # alinhado à direita em 8 casas
print(f"{1234567.891:,.2f}")  # separador de milhar

Para o formato brasileiro (vírgula decimal), troque os caracteres:

valor = 1234.5
texto = f"{valor:,.2f}".replace(",", "X").replace(".", ",").replace("X", ".")
print("R$", texto)   # R$ 1.234,50

Modelo pronto para os exercícios de sequência

Exercício 47 (aumento de 22%) e 66 (IMC) no mesmo formato. Repare: entrada, conta, saída.

salario = float(input("Salário: "))
novo_salario = salario * 1.22          # 22% a mais = multiplicar por 1.22
print(f"Novo salário: R$ {novo_salario:.2f}")

Porcentagens: aumento de 22% → valor * 1.22. Desconto de 20% → valor * 0.80. "X% de valor" → valor * X / 100.

print(4/3 * math.pi * raio**3)   # volume da esfera
Lição 6 · Seleção

Decisões com if, elif e else

A estrutura de seleção escolhe qual bloco executar conforme uma condição. Exercícios 72 a 115.

A forma geral

media = float(input("Média: "))

if media >= 7:
    print("Aprovado")
elif media >= 5:
    print("Recuperação")
else:
    print("Reprovado")

print("Fim")  # fora do if: roda sempre
  • Todo if, elif e else termina com dois-pontos :.
  • O bloco de dentro tem 4 espaços de recuo. É o recuo que diz o que está dentro do if (no Portugol era o fim_se).
  • O Python testa de cima para baixo e executa só o primeiro bloco verdadeiro.

Faixas de valores

Tabelas como as dos exercícios 77, 96, 97 e 114 viram uma cadeia de elif. Como o primeiro verdadeiro ganha, você só precisa testar o limite de cima:

salario = float(input("Salário atual: "))

if salario <= 1000:
    aumento = 0.20
elif salario <= 5000:      # aqui já sabemos que é > 1000
    aumento = 0.10
else:
    aumento = 0.0

print(f"Novo salário: R$ {salario * (1 + aumento):.2f}")

Python aceita comparações encadeadas, como na matemática:

n = 5
print(1 <= n <= 9)      # exercício 87: está na faixa?
idade = 15
print(16 <= idade < 18) # voto facultativo?

Condições compostas

idade, tempo = 61, 26
# exercício 115: qualquer um dos requisitos serve -> OR
if idade >= 65 or tempo >= 30 or (idade >= 60 and tempo >= 25):
    print("Requerer aposentadoria")
else:
    print("Não requerer")

Ifs aninhados

Um if dentro do outro. Útil quando a segunda pergunta só faz sentido depois da primeira (exercício 84):

notas = [float(input(f"Nota {i}: ")) for i in range(1, 5)]

if media >= 7:
    print(f"Aprovado com média {media:.1f}")
else:
    exame = float(input("Nota do exame: "))
    nova = (media + exame) / 2
    if nova >= 5:
        print(f"Aprovado em exame com média {nova:.1f}")
    else:
        print(f"Reprovado com média {nova:.1f}")

If de uma linha

n = 7
paridade = "par" if n % 2 == 0 else "ímpar"
print(n, "é", paridade)

Valores "verdadeiros" e "falsos"

Zero, texto vazio "", lista vazia [] e None contam como falso. O resto conta como verdadeiro.

Lição 7 · Múltipla escolha

Escolha-caso: match, elif e dicionários

Quando uma variável pode ter vários valores e cada um leva a uma ação diferente (menus, códigos de produto, meses). Exercícios 116 a 122.

match / case (Python 3.10+)

É o escolha do Portugol. O case _ é o "senão" (qualquer outro valor).

codigo = int(input("Código do produto: "))
match codigo:
    case 1:
        print("Alimento não-perecível")
    case 2 | 3 | 4:                       # vários valores no mesmo caso
        print("Alimento perecível")
    case 5 | 6:
        print("Vestuário")
    case 7:
        print("Higiene Pessoal")
    case n if 8 <= n <= 15:             # faixa com "guarda"
        print("Limpeza e Utensílios Domésticos")
    case _:
        print("Código inválido")

Com elif (funciona em qualquer versão)

codigo = 3
if codigo == 1:
    print("Alimento não-perecível")
elif codigo in (2, 3, 4):
    print("Alimento perecível")
else:
    print("Outro")

Tabela de preços com dicionário

Quando a escolha é só "buscar um valor numa tabela" (cardápios dos exercícios 116 e 117), um dicionário resolve sem nenhum if:

cardapio = {
    100: ("Cachorro quente", 1.20),
    101: ("Bauru simples", 1.30),
    102: ("Bauru com ovo", 1.50),
    103: ("Hambúrguer", 1.20),
    104: ("Cheeseburguer", 1.30),
    105: ("Refrigerante", 1.00),
}
codigo = int(input("Código: "))
qtd = int(input("Quantidade: "))
if codigo in cardapio:
    nome, preco = cardapio[codigo]
    print(f"{qtd}x {nome} = R$ {qtd * preco:.2f}")
else:
    print("Código inválido")

Menu que repete

Exercício 121 e a calculadora: um menu dentro de um laço, que só para quando o usuário escolhe sair.

while True:

Laços: for e while

Repetir um bloco várias vezes. É o maior capítulo da lista (123 a 187) e o que mais treina lógica.

for com range: quando você sabe quantas vezes

for i in range(5):          # 0, 1, 2, 3, 4
    print(i, end=" ")

for i in range(1, 11):      # 1 até 10 (o 11 não entra!)
    print(i, end=" ")
print()
for i in range(10, 0, -1):  # 10 até 1, contando para trás (ex. 139)
    print(i, end=" ")
print()
for i in range(10, 1001, 10):  # 10, 20, ..., 1000 (ex. 136)
    pass
print("último:", i)
PortugolPython
para i de 1 até N façafor i in range(1, n + 1):
para i de N até 1 passo -1for i in range(n, 0, -1):
para i de 0 até 100 passo 2for i in range(0, 101, 2):

while: enquanto a condição for verdadeira

contador = 1
while contador <= 5:
    print("Volta", contador)
    contador += 1      # sem isso o laço nunca acaba!

Laço infinito: se a condição do while nunca ficar falsa, o programa não para. Aqui no navegador isso trava a aba. Confira sempre se alguma coisa dentro do laço muda a condição.

3. Maior e menor

Comece com o primeiro valor (não com zero!) e compare com cada um dos outros.

n = int(input("Quantos números? "))
maior = menor = None
for i in range(n):
    x = int(input(f"Número {i + 1}: "))
    if maior is None or x > maior:
        maior = x
    if menor is None or x < menor:
        menor = x
print("Maior:", maior, "Menor:", menor)

4. Flag (valor de parada)

"Leia até digitar 0" (exercícios 130, 135, 156, 173). O 0 não entra na conta.

soma = 0
quantidade = 0
numero = int(input("Número (0 para parar): "))
while numero != 0:

    quantidade += 1
    numero = int(input("Número (0 para parar): "))

if quantidade > 0:
    print("Média:", soma / quantidade)

Funções: dar nome a um pedaço de código

Uma função recebe dados (parâmetros), faz um trabalho e pode devolver um resultado (return). Sem return ela é o que o Portugol chama de procedimento.

Definindo e chamando

def saudacao(nome):                 # procedimento: só mostra
    print(f"Olá, {nome}!")

def area_retangulo(base, altura):   # função: devolve um valor
    return base * altura

print(area_retangulo(2.5, 2) + 1)

print vs return: print só mostra na tela. return entrega o valor para quem chamou, que pode guardar numa variável, fazer contas ou mostrar. Nos exercícios com correção automática, a função precisa retornar.

Parâmetros com valor padrão e nomeados

def preco_final(preco, desconto=0.0, frete=10):
    return preco * (1 - desconto) + frete

print(preco_final(100, 0.2))             # 90.0
print(preco_final(100, frete=0))         # 100.0

Retornando vários valores

O que é criado dentro da função só existe lá dentro. Para usar fora, devolva com return.

Lição 16 · Extra: orientação a objetos

Classes e objetos

Uma classe junta dados (atributos) e ações (métodos). É o próximo passo depois dos registros e o que vem no módulo seguinte do curso.

Criando uma classe

class ContaBancaria:
    def __init__(self, titular, saldo=0):   # construtor
        self.titular = titular
        self.saldo = saldo

    def depositar(self, valor):
        self.saldo += valor

    def sacar(self, valor):
        if valor > self.saldo:
            return False
        self.saldo -= valor
        return True

    def __str__(self):                     # como o objeto aparece no print
        return f"{self.titular}: R$ {self.saldo:.2f}"

conta = ContaBancaria("Ana", 100)
conta.depositar(50)
print(conta.sacar(500), conta.sacar(30))
print(conta)
  • self é o próprio objeto. Todo método recebe ele primeiro.
  • __init__ roda quando você cria o objeto.
